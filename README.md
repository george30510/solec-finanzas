# Solec Finanzas

Sitio web de Lizeth Solórzano Lecona — asesora financiera independiente / consultora en previsión financiera y beneficios corporativos.

- Marca del sitio: **Solec Finanzas** (solecfinanzas.com) — marca corporativa dirigida a empresas que contratan seguros colectivos. Distinta de su marca personal "LS", que no se usa aquí.
- Cliente de: **Cuadrado Circular**

## Contenido de este repo

- `solec-demo.html` — demo visual de una página (Paso 3 del proceso ya cotizado). Standalone, sin backend, sin build step. Ábrelo directo en el navegador.
- `PROGRESS.md` — estado del proyecto, decisiones de diseño ya tomadas, y qué falta por resolver antes de construir el sitio completo.
